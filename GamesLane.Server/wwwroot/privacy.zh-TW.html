隱私權政策

最後更新：2026 年 11 月 11 日

GamesLane 是一個免費、非商業性的網站，供您與親友一起玩桌上遊戲和紙牌遊戲。本頁說明網站會使用哪些資訊以及使用的原因。

我們使用的資訊

  • 您的顯示名稱和頭像，由您自己選擇。它們會顯示給同一局遊戲中的其他人。
  • 如果您建立帳號：您的使用者名稱和密碼。密碼僅以加密形式（加鹽雜湊）儲存，因此任何人（包括 GamesLane）都無法讀取。
  • 如果您使用 Google、Microsoft 或 Discord 登入：您在該服務上的帳號 ID，僅用於下次辨識您；以及您的名稱和大頭貼，僅使用一次，作為您預設的顯示名稱和頭像。GamesLane 永遠不會看到您在該服務上的密碼，也不會保留您的電子郵件地址。
  • 如果您上傳圖片作為頭像：該圖片的一份小尺寸副本（128×128 像素）。
  • 遊戲資訊：您建立或加入的遊戲，以及您的每一步操作。
  • 聊天訊息：您在遊戲中寫的訊息，以及您的顯示名稱和頭像。所有開啟該遊戲的人（玩家和觀戰者）都能看到。

資訊的儲存方式

  • 訪客（所有未使用帳號登入的人）的資訊只儲存在其瀏覽器的本機儲存空間中，絕不會儲存在伺服器上，而且不會過期。
  • 帳號（使用者名稱帳號或 Google/Microsoft/Discord 帳號）儲存在資料庫中：包括上述資訊、您的聊天和音效設定，以及帳號的建立時間和最後使用時間。30 天未使用的帳號會被自動刪除，其圖片也會一併刪除。
  • 遊戲儲存在資料庫中，因此在中斷或伺服器重新啟動後可以繼續。已開始的遊戲會在所有人離開 6 小時後刪除；從未開始的遊戲會在所有人離開後很快刪除。
  • 每局遊戲只保留最近的 100 則聊天訊息，這些訊息會與遊戲一起刪除。
  • 您的瀏覽器會儲存一個登入權杖。對於帳號，它會讓您在最後一次造訪後最多 30 天內保持登入，或直到您登出。對於訪客，它儲存訪客的顯示名稱和頭像，並一直保留到您清除瀏覽器的網站資料為止。
  • 當您使用 Google、Microsoft 或 Discord 登入時，會短暫使用一個 Cookie 來完成登入，隨後將其移除。
  • 您的瀏覽器會儲存您最後一次造訪的日期，以及您當天開啟過頁面的遊戲，以便每次造訪每天只計算一次。這些資訊不會傳送到伺服器；只會傳送這是否是您的首次造訪，或距上次造訪已過了幾天。

資訊分享

您的資訊不會被出售或與任何人分享，也不會用於廣告。網站沒有任何第三方分析或追蹤工具，也沒有追蹤 Cookie。網站只保存匿名的每日統計數字，不包含任何能辨識您或您的瀏覽器的資訊：每天各類遊戲被建立、加入、開始和完成的數量，邀請連結被開啟的次數，以及網站的造訪次數，包括造訪來源（其他網站或推廣連結）、瀏覽器語言，以及訪客是新訪客還是回訪者。

本網站由 Render 代管，資料庫由 Neon 提供，頁面會從 jsDelivr 內容傳遞網路載入一個指令碼。與任何網路服務一樣，這些服務供應商可能會處理您的 IP 位址以提供網站服務。

您透過傳送意見回饋表單傳送的意見會以公開 issue 的形式張貼在 GitHub 上，任何人都可以閱讀，其中會附上傳送時所在的頁面和語言；只有在您選擇附上名稱時，才會包含您的顯示名稱。

兒童

GamesLane 適合家庭使用。帳號是選用的；每個人一開始都是訪客，不需要提供任何帳號資訊即可遊玩。

聯絡我們
